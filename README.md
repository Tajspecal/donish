# Дониш — платформа онлайн-тестирования студентов

Flask + SQLite + HTML/CSS/JavaScript. Студенты проходят тесты и сразу видят результат.
Преподаватели создают, редактируют и удаляют тесты, загружают их из файла JSON или
генерируют с помощью бесплатного Gemini API. Администратор управляет ролями пользователей.

## Запуск

```bash
pip install -r requirements.txt     # нужен только Flask
copy .env.example .env              # Linux/macOS: cp .env.example .env
python app.py
```

Откройте http://127.0.0.1:5000

При первом запуске создаётся пустая база `donish.db` и администратор
с логином и паролем из `.env` (`ADMIN_USERNAME` / `ADMIN_PASSWORD`, по умолчанию `admin` / `admin123`).
**Смените пароль в `.env` до первого запуска.** Если база уже создана — удалите `donish.db`
или смените пароль в панели.

## Роли

| Действие                                  | Студент | Преподаватель | Администратор |
|-------------------------------------------|:-------:|:-------------:|:-------------:|
| Регистрация, вход, прохождение тестов     |   да    |      да       |      да       |
| Создание/изменение/удаление тестов        |   нет   |      да       |      да       |
Просмотр результатов своих тестов           |   нет   |      да       |      да       |
| Импорт из файла, генерация через Gemini   |   нет   |      да       |      да       |
| Пользователи: роли и удаление             |   нет   |      нет      |      да       |

Регистрация всегда создаёт студента. Роль «преподаватель» назначает администратор:
панель → вкладка «Пользователи». Роль проверяется на сервере при каждом запросе.

## Генерация тестов (Gemini)

1. Получите бесплатный ключ в Google AI Studio: https://aistudio.google.com/api-keys
2. Впишите его в `.env`: `GEMINI_API_KEY=ваш_ключ` и перезапустите сервер.
3. Панель → «✨ Сгенерировать» → тема, число вопросов, сложность → проверьте черновик → «Сохранить тест».

Черновик в базу не пишется, пока преподаватель его не сохранит. Ключ хранится только на сервере.
Название модели меняется в `.env` (`GEMINI_MODEL`) — Google периодически обновляет список моделей.
У бесплатного уровня есть лимиты запросов; при их превышении сайт покажет сообщение, а подробности — в консоли сервера.
Между генерациями одного пользователя пауза 10 секунд (`GENERATE_PAUSE`).

## Формат файла для импорта

```json
{
  "title": "Основы Python",
  "description": "Базовые понятия языка",
  "questions": [
    {
      "question_text": "Какой функцией выводят текст на экран?",
      "options": ["print()", "echo()", "write()", "console.log()"],
      "correct_answer": 0
    }
  ]
}
```

`correct_answer` — номер правильного варианта, начиная с 0. Вопросов — до 20, вариантов — от 2 до 6.
Файл открывается в редакторе, где его можно поправить до сохранения.

## Формат вопроса «на соответствие»

В редакторе тип вопроса можно выбрать как `На соответствие`. Также этот формат поддерживается
при импорте JSON:

```json
{
  "test_type": "matching",
  "title": "Основы программирования",
  "duration_minutes": 15,
  "questions": [
    {
      "question_type": "matching",
      "question_text": "Сопоставьте понятие и описание",
      "pairs": [
        {"left": "Переменная", "right": "Хранит значение"},
        {"left": "Функция", "right": "Выполняет действия"},
        {"left": "Цикл", "right": "Повторяет действия"}
      ]
    }
  ]
}
```

`duration_minutes` необязателен: если его не указать, тест будет без ограничения времени.
Допустимое время — от 1 до 600 минут.

## Структура

| Файл                              | Назначение                                              |
|-----------------------------------|---------------------------------------------------------|
| `app.py`                          | Создание приложения и запуск                            |
| `config.py`                       | Настройки, чтение `.env`                                |
| `database.py`                     | SQLite, создание таблиц, первый администратор           |
| `schema.sql`                      | Пустые таблицы users, tests, questions, results            |
| `auth.py`                         | Регистрация, вход, выход, проверка роли                 |
| `quiz.py`                         | Тесты для студентов, подсчёт баллов на сервере, история |
| `admin.py`                        | Панель: тесты, вопросы, импорт, генерация, пользователи |
| `gemini.py`                       | Запрос к Gemini API и проверка ответа                   |
| `templates/index.html`            | Общая оболочка страницы и подключения частичных шаблонов |
| `templates/_*.html`               | Частичные шаблоны отдельных экранов                     |
| `templates/static/css/style.css`  | Оформление, адаптивная вёрстка                          |
| `templates/static/js/app.js`      | Вход, список тестов, прохождение, история               |
| `templates/static/js/admin.js`    | Панель преподавателя и редактор теста                   |
| `tests/test_app.py`               | Автотесты (Gemini подменяется локальной заглушкой)      |

## Проверка

```bash
python -m unittest discover -s tests -v
```

## Маршруты

Студент: `POST /api/register`, `POST /api/login`, `POST /api/logout`, `GET /api/me`,
`GET /api/tests`, `GET /api/tests/<id>/questions`, `POST /api/submit`, `GET /api/results`.

Преподаватель и администратор: `GET|POST /api/admin/tests`, `GET|PUT|DELETE /api/admin/tests/<id>`,
`GET /api/admin/tests/<id>/results`, `POST /api/admin/import`, `POST /api/admin/generate`.

Только администратор: `GET /api/admin/users`, `PUT /api/admin/users/<id>/role`, `DELETE /api/admin/users/<id>`.
